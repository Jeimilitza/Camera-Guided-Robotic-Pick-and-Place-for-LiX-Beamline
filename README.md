# Camera-Guided-Robotic-Pick-and-Place-for-LiX-Beamline
Camera-Guided Robotic Pick-and-Place for LiX Beamline

This repository includes files pertaining to different stages of the project, such as repeatability testing, pick and place algorithms and camera calibration for April tag detection.



# Project Dependencies

## 1. Operating System
- Ubuntu: Noble Numbat (24.04)
- ROS 2: Jazzy Jalisco

## 2. ROS 2 Packages
- rclpy
- geometry_msgs
- sensor_msgs
- std_msgs
- tf2_ros
- moveit_msgs
- moveit_ros_planning_interface
- ros2_control
- ros2_controllers
- ur_robot_driver
- Robotiq Hand-E driver

## 3. Python Libraries
- OpenCV (cv2)
- NumPy
- Pandas
- Pupil AprilTags
- VmbPy (Python API of the Vimba X SDK)

## 4. Robotics and Motion Planning
- MoveIt 2
- Universal Robots ROS 2 Driver
- Robotiq Hand-E Driver
- ROS 2 Control

## 5. Hardware Requirements
- Universal Robots UR5e
- Robotiq Hand-E gripper
- Camera
- AprilTag markers
